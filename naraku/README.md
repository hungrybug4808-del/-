# 奈落（落下音ゲー）

巨大な縦穴を落ちながら、拍に合わせて迫る敵と障害物に矢印キーで対処するリズムゲーム。
`index.html` の1ファイルだけで動く（Three.js と Google Fonts を CDN から読み込むので、ネットにつながった状態で開く）。

## 遊び方

- `index.html` をブラウザで開く（ES モジュールを使うので、うまく動かないときは `npx serve naraku` などで配信して開く）
- ↑ → ↓ ← ：その方向から来たものに対処する。金の目＝敵（斬る）、赤橙のふち＝障害物（よける）
- 判定はノーツがリングに重なる時刻の ±0.1 秒。外す・押し忘れ・方向違いは1回でゲームオーバー
- Esc：プレイ中ならマップへ戻る

## しくみ

| 部分 | 中身 |
| --- | --- |
| 曲とノーツ | `buildSong()` が、層ごとのテンポ・調・コード進行と、プレイごとに変わる乱数シードから、ノーツ（敵・障害物）と曲のイベントを同じデータから作る。曲は「静か→盛り上がり→サビ（最後に斬り見せ場）→決め」を1セットとして、層の長さぶん並べる |
| 音 | Web Audio でプログラム合成（チェレスタ＝FM、ハープ、弦、合唱＝フォルマント、太鼓、低い鐘、ノイズから作ったリバーブ）。先読みスケジューラで `AudioContext.currentTime` を基準に鳴らし、判定も同じ時刻で行う |
| 画面 | Three.js。トンネルはチャンクを流して使い回す。層ごとの景色は `THEMES` と `DECOR`、発光は UnrealBloomPass、奥行きは FogExp2 |
| 保存 | `localStorage` の `naraku.save.v1` に、層ごとのクリア済みと最高到達深度 |

## 素材確認モード

タイトル画面右下の「素材確認モード」（`#assets`）から入る。素材を作り直す順（プレイヤー → 一層の敵 → 一層の障害物 → 一層の背景 → エフェクト → 二層以降）に並び、それぞれの確認状態と、下の各ビューアへの入口がある。

## 設定

タイトル画面・マップから開く（`#settings`）。タイミング調整（±0.2秒、0.01秒刻み）と、カチッという音に合わせて押すとずれを測る機能。値は `localStorage` に保存する。

## プレイヤーの動きビューア

`index.html?viewer`（タイトル画面右下の「プレイヤーの動きを見る」からも開ける）。ゲーム本体と同じプレイヤー・演出のコードで、動きを1つずつ再生できる。

- 動き：斬る／身を翻す／反対側へ移る（それぞれ4方向）、連撃（3体・4体・斬り見せ場）、とどめ、ゲームオーバー、層のクリア
- マウスで全方位から見られる（ドラッグで回転、ホイールで拡大）。カメラのプリセット（ゲームの視点・後ろ・前・横・上・下）と自動回転
- 再生速度（×1〜×0.1）、敵・障害物を出すか、判定リング、落下の有無、背景の層を切り替えられる
- キー：矢印＝斬る、Shift＋矢印＝身を翻す、Alt＋矢印＝反対側へ移る、Space＝連撃、R＝リセット

## 敵・障害物ビューア

`index.html?bestiary`（タイトル画面右下の「敵・障害物を見る」からも開ける）。ゲームと同じモデルを使う。

- 7層ぶんの敵・障害物（小）・障害物（大）から選び、名前・特徴・プレイヤーの対処を表示
- 見せ方：**標本**（1体を大きく。斬られる／とどめで散る）、**ゲームでの見え方**（奥からリングへ繰り返し来る。来る方向と、プレイヤーが対処するかを選べる）、**一覧**（7層ぶんを並べて比べる）
- マウスで全方位から見られる。カメラのプリセット、自動回転、再生速度、背景（その層の穴）の切り替え
- キー：←→＝層、↑↓＝敵・小・大、Space＝斬られる、M＝見せ方

## 背景ビューア

`index.html#scenery`（タイトル画面右下の「背景」からも開ける）。

- 7層と奈落の底の景色を切り替え、名前・深さ・見どころ（壁の飾りや滝・泡などの特別な景色）・霧の色を表示
- カメラ：ゲームの視点／奥を見下ろす／見上げる／壁に寄る／ななめ、自動回転。マウスで全方位から見られる
- 落下の速さ（止める〜×2）、霧・プレイヤー・ランプの光・判定リング・敵と障害物の表示を切り替え
- 「層のクリア → 次の層へ」で、ゲームと同じ切り替えの演出を再生
- キー：←→＝層、Space＝次の層へ

ビューアどうしは `#viewer` / `#bestiary` / `#scenery` / `#title` で、ページを読み込み直さずに行き来する（`?viewer` などのクエリでも開ける）。

## 確認用の URL パラメータ

- `?auto`：自動で全部成功させる（演出の確認用）
- `?unlock`：全層を選べるようにする
- `?skip=秒`：曲の途中から始める
- `?viewer`：プレイヤーの動きビューア
- `?bestiary`：敵・障害物ビューア
- `?scenery` または `#scenery`：背景ビューア
