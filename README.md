# 魔王軍略（仮）

ブラウザで遊べる3D対戦ストラテジーゲーム。コストを払ってモンスターを出し、自動で進軍させて相手の魔王城を落とす。
three.js + TypeScript + Vite。キャラクター・建物・地形はすべてコードで組んだボクセル。

## 動かし方

```sh
npm install
npm run dev      # 開発サーバー（同じネットワークのスマホからも開ける）
npm run build    # dist/index.html に1ファイルでまとめて出力（ダブルクリックで開ける）
```

## 構成

| 場所 | 中身 |
| --- | --- |
| `src/core/` | 数学（キーフレーム `kf`・イージング・`hash`）と、ボクセルの仕組み（`Vox` / `tpl` / `part`） |
| `src/render/stage.ts` | レンダラー・シーン・カメラ・ライト（空の光と太陽）・画面テーマ |
| `src/fx/effects.ts` | 粒のプール、土煙・輪・光の粒、画面の揺れ |
| `src/units/` | モンスター1体につき1ファイル（モデル・モーション・攻撃）。`registry.ts` に登録 |
| `src/battle/` | 対戦ルール（`world.ts`）、ユニットの行動、建物、竜脈、矢、試合進行と CPU（`battle.ts`） |
| `src/terrain/` | ブロック地形のデータ（`grid.ts`）、最初のマップの生成（`generate.ts`）、メッシュ化、飾り、陸の経路探索（`nav.ts`） |
| `src/world/` | 地形・水（川の流れ・滝・渦潮）の描画と、空の気候（雲・雪・雨・砂嵐） |
| `src/ui/`, `src/input/` | HUD と手札、カメラ操作（移動・回転・ズーム）とタップでの出撃 |
| `prototypes/` | チャットで作った試作 HTML（見た目・モーションの基準） |

### モンスターを増やすとき

`src/units/archer.ts` などと同じ形で `UnitDef` を1つ作り、`src/units/registry.ts` の `DEF` と `HAND` に足す。

## 最初のマップ

左右対称（z=0 が中央）。魔王城は z=±30 で、背中側（|z|>33）は海。南（画面右）から北（画面左）へ：

- 海の通り道（島・渦潮・海の竜脈）と、城の背中側の海
- 南の低地：海岸・砂浜・砂漠・荒野・沼地（川の河口、雨雲）
- 中央の平らな道：平原・草原・中央の丘（竜脈）。川が丘の両側に分かれ、道の上が渡河点
- 丘陵と森林（崖のある段丘）。その上空に、空の竜脈を載せた浮島
- 絶壁の上の高台：川の谷と渡河点、尾根を抜ける洞窟。城の近くの坂から上れる
- 山岳と高山（雪）、山の湖。湖から高台へ、高台から低地へ滝が落ちる

陸のモンスターは1ブロック（0.5）の段差まで上り下りでき、2ブロック以上は崖として通れない。深さ2ブロック以上の水には入れない。
高台にいる陸の遠距離モンスターは、相手より 1 高いごとに射程 +0.5（最大 +2）。近接は高さの差が 1 以内の相手にしか当たらない。

## 陸・海・空

- 陸：地面を歩く。沼地と砂漠では移動が 30% 遅くなる
- 海：海面とつながる水（海・川・沼地の浅瀬・渡河点）を泳ぐ。滝の上の川や山の湖へは行けない。水辺の魔王城は裏の海から攻撃できる
- 空：地形に関係なく飛ぶ（山や浮島の上は高度を上げる）
- 近接は同じ場所の相手だけ、遠距離はどこにでも当たる（弓兵のように空も撃てるかは種類による）
- 竜脈：陸（中央の丘）は陸と空、海（海の真ん中）は海と空、空（浮島）は空のモンスターだけが占領できる。1か所につき魔素の回復 +50%

## 旗

「🚩 旗」で旗モードに入り、動かしたい自軍のモンスターをタップして選び（足元の輪が黄色になる）、地面をタップすると旗が立つ。
選んだモンスターは旗へ向かい（途中は攻撃が届く相手とだけ戦う）、着いたら旗のまわりを守る。旗をタップすると外れて自動進軍に戻る。
旗へたどり着けないモンスター（陸の奥の旗と海のモンスターなど）は、旗を無視して自動で進軍する。
