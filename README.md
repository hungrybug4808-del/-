# 魔王軍略（仮）

ブラウザで遊べる3D対戦ストラテジーゲーム。コストを払ってモンスターを出し、自動で進軍させて相手の魔王城を落とす。
three.js + TypeScript + Vite。キャラクター・建物・地形はすべてコードで組んだボクセル。

## 動かし方

```sh
npm install
npm run dev      # 開発サーバー（同じネットワークのスマホからも開ける）
npm run build    # dist/index.html に1ファイルでまとめて出力（ダブルクリックで開ける）
                 # あわせて、キャラ図鑑を dist/characters/<キャラ>.html に1体ずつ出力
```

### キャラ図鑑

試作の cyclops.html などと同じように、キャラを1体ずつ出して、モーション（召喚・待機・移動・攻撃・被弾・撃破、サイクロプスの城への攻撃とアイビーム、バディの提案・喜ぶ・スキル）をボタンで1つずつ再生できる。
ゲーム本体と同じキャラの定義（`src/units/`・`src/buddy/`）を使うので、キャラを直せば図鑑にもそのまま反映される。

- ビルド後：`dist/characters/cyclops.html` のように、キャラごとに1ファイル（ダブルクリックで開ける）。上の一覧から他のキャラにも切り替えられる
- 開発中：`npm run dev` のあと `/chara.html#cyclops` を開く

### モンスターを増やすとき

`src/units/archer.ts` などと同じ形で `UnitDef` を1つ作り、`src/units/registry.ts` の `DEF` と `HAND` に足す。

## ワールド

試合の前に、気候ごとの4つの国から選ぶ（「もう一度」でも選び直せる）。どの国も左右対称（z=0 が中央）で、魔王城（z=±30）・砦（z=±20）・陸の道3本・水の道・竜脈3か所（陸・海・空）がある。定義は `src/terrain/maps/` に1国1ファイル。

- 魔王城の左右と背中は**堀**。海のモンスターは、川や水路を通って敵の堀まで行き、そこから魔王城を攻撃する（すぐそばの海はなくした）
- マップの外も、その国の地形が続く（遠くほど粗いブロックで描く、見た目だけ）

| 国 | 気候 | 地形 | 陸の道 | 水の道 | 竜脈（陸／海／空） |
| --- | --- | --- | --- | --- | --- |
| 🌿 草原の国 | 温帯 | なだらかな丘の続く田園 | 西の田園（川の向こう、小川の浅瀬を渡る）／中央の丘／東の丘陵（少し高い）。中央と東の間は森の帯 | 西の丘から小川が池に注ぎ、池から川が南北の堀へ | 中央の丘／池／浮島 |
| 🏔️ 霊峰の国 | 寒冷・雪 | 雪山の連なる造山帯。2本の尾根が3つの谷に分ける | 西の谷／中央の谷／東の谷（一段高い、凍った湖）。尾根は峠だけ越えられる | 氷河から氷河湖へ流れ込み、西の谷の川が南北の堀へ | 中央の岩の丘／氷河湖／東の尾根の頂 |
| 🏞️ 湖水の国 | 温暖 | 石灰岩の柱（カルスト）が林立する湖に浮かぶ白い石の水の都 | 水の上の通路：西の回廊／中央の大通り（広場）／東の回廊。飛び石で乗り換え | 通路の間はすべて水路。陣地の水路から堀へ | 広場の台／水路／石灰岩の柱の上 |
| 🏜️ 峡谷の国 | 乾燥・砂嵐 | 赤い地層の台地を割る、うねる峡谷。天然の石のアーチ | 西の台地／うねる峡谷（谷底、両側から撃ち下ろされる）／東の台地 | 谷底の川がオアシスの泉を通り、陣地で2つに分かれて堀へ | オアシス／泉／西の台地の岩山 |

- 自動で進むモンスターは、中盤（|z|<17）では出した道をそのまま進む。道の乗り換え（峠・森の小道・飛び石・川の浅瀬）は、旗で指示したときだけ
- 砦にたどり着けるモンスターは、その砦を落とすまで魔王城を狙わない。海のモンスターは砦に関係なく、堀から魔王城を攻撃できる

陸のモンスターは1ブロック（0.5）の段差まで上り下りでき、2ブロック以上は崖として通れない。深さ2ブロック以上の水には入れない。
高台にいる陸の遠距離モンスターは、相手より 1 高いごとに射程 +0.5（最大 +2）。近接は高さの差が 1 以内の相手にしか当たらない。

## 陸・海・空

- 陸：地面を歩く。沼地と砂漠では移動が 30% 遅くなる
- 海：堀とつながる水（川・池・水路・浅瀬）を泳ぐ。滝の上など、高さのちがう水へは行けない。魔王城は堀から攻撃できる
- 空：地形に関係なく飛ぶ（山や浮島の上は高度を上げる）
- 近接は同じ場所の相手だけ、遠距離はどこにでも当たる（弓兵のように空も撃てるかは種類による）
- 竜脈：陸の竜脈は陸と空、海の竜脈は海と空、空の竜脈（浮島や高い岩の上）は空のモンスターだけが占領できる。1か所につき魔素の回復 +50%

## 旗

「🚩 旗」で旗モードに入り、動かしたい自軍のモンスターをタップして選び（足元の輪が黄色になる）、地面をタップすると旗が立つ。
選んだモンスターは旗へ向かい（途中は攻撃が届く相手とだけ戦う）、着いたら旗のまわりを守る。旗をタップすると外れて自動進軍に戻る。
旗へたどり着けないモンスター（陸の奥の旗と海のモンスターなど）は、旗を無視して自動で進軍する。
